# EC AI · Electronic Commerce AI

一款面向天猫平台店铺的 **Windows 桌面版电商数据分析工作台**（单机、离线、一人一份）。

把生意参谋与自制报表「导入 -> 看板 -> AI 评语 -> 日报导出」在本地闭环：数据只存在自己电脑，不花服务器钱，同事间用「数据包」文件互传数据。

---

## 特性

- 多店铺管理：增删改、设默认店铺、店铺间一键切换与对比
- 九源数据导入：拖拽批量导入经营 / 商品 / 推广 / 咨询 / 搜索词 / DSR / 客服 / 退款等 9 类文件，自动识别数据源、表头偏移容错、重复导入不翻倍、导入历史可查
- 数据看板：近 7 / 15 / 30 天窗口全局联动，9 大区块（摘要 / 指标 / 趋势 / 商品 / 推广 / 退款 / DSR+客服 / 搜索词 / 建议动作），数字均可回溯到源文件
- AI 评语：按看板模块调用对应技能（skill）生成专业评语，支持自配 OpenAI 兼容 / Anthropic 等模型；未配置模型时不崩溃
- AI 对话：ChatGPT 式多会话聊天，流式回复、斜杠调技能、附件上传（图片 / 文件 / 文件夹）、引用当前看板数据与只读查库模板
- 聊天质检：导入客服聊天记录（csv / txt / json），按可编辑提示词交给 AI 质检，生成 markdown 报告并可导出
- 投产比计算：推广花费 / 成交 / 退款率 / 毛利率一键算出投产比、营销占比、保本 ROI，并可带入看板真实数据
- 日报 / 周报导出：一键导出离线可打开的 HTML（内嵌图表与 AI 评语），也可导出 PDF 与明细 csv / xlsx
- 数据包：按店铺 + 日期范围导出加密 zip 数据包（SQLite 副本 + 清单校验），导入端校验数量与校验和，重复导入不重复
- 技能管理：从 GitHub 链接或本地目录解析安装 skill，可编辑提示词，并给看板各大模块绑定对应技能
- 外观与体验：7 套主题（含 Spotify 暗色风）、自定义背景图、自定义头像、开屏问候、无边框自绘 UI、全应用无 emoji
- 离线授权：管理员用独立授权工具签发机器绑定激活文件；未授权 / 非绑定机器无法进入主界面

## 技术栈

- Electron 43 + electron-vite
- Vue 3 + TypeScript + Pinia + Vue Router
- better-sqlite3（SQLite，WAL 模式，导入时完成聚合，看板只读聚合表）
- ECharts（按需引入）
- Tailwind（样式体系）与自绘 SVG 线性图标

## 开发

环境要求：Node.js 22+、npm 10+

```bash
npm install          # 安装依赖
npm run dev          # 开发启动（弹窗调试）
npm run typecheck    # 类型检查（node + web）
npm test             # 单元测试（vitest）
npm run build        # 构建三端产物
npm run dist:win     # 打包 NSIS 安装包（release/）
```

## 数据导入

支持的文件类型与解析规则详见 [docs/数据源清单.md](docs/数据源清单.md)。9 类数据源包括：

- 经营数据（xlsx，宽表）
- 商品报表 / 商品明细（xls / xlsx）
- 推广报表（csv，gbk）
- 咨询数据（csv，utf-8-sig）
- 搜索词（xls，表头偏移容错）
- DSR 评分（xlsx）
- 客服绩效（xlsx）
- 退款单（xlsx，53 列）

导入采用「本地解析为主，AI 兜底」双重保险：本地解析规则写得非常严格，一旦字段对不上（平台改版等），自动交给大模型按既定规范重新解析落库；仍无法识别则进入人工处理流程并留痕。

## 授权说明

本软件采用离线机器码授权：

- 应用设置页显示机器码哈希（不泄露硬件原始信息）
- 管理员使用独立的授权工具（见 `tools/license-tool`）为机器码签发 `.lic` 激活文件
- 激活文件与机器码绑定，改一个字节即失效；支持有效期、万能解锁（管理员上门开锁）


> 注意：软件是vibecoding的，上传GitHub是为了备份和更新，这个授权机制如果不需要让codex读一遍代码给拆了

## 数据与隐私

- 所有经营数据只存本机（`%APPDATA%\EC AI`），不上传任何云
- AI 调用仅发往用户自行配置的模型服务商，且仅发送当前窗口聚合数据
- API Key 使用系统安全存储加密，界面只显示「已设置 / 未设置」
- 日志与诊断包导出会做脱敏
